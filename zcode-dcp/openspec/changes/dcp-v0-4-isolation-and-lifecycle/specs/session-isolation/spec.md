# Spec Delta

## Purpose

消除多会话并发时的状态串扰：提醒状态按会话隔离，计量严格匹配会话日志，杜绝"读别人的日志、重置别人的冷却"。

## ADDED Requirements

### Requirement: 提醒状态按会话隔离

分级提醒的冷却与层级状态 SHALL 按会话隔离存储，一个会话的提醒注入与状态更新不得影响其他并行会话的提醒节奏。

#### Scenario: 双会话互不干扰

- **WHEN** 会话 A 刚注入 tier1 提醒，会话 B 首次达到阈值
- **THEN** 会话 B 正常注入提醒，不被 A 的冷却抑制

### Requirement: 计量严格匹配会话

当 hook 输入携带 session_id 且其对应的模型 IO 日志文件不存在时，SHALL 跳过本轮计量与提醒；仅当输入不含 session_id 时才允许回退到最近修改的日志。

#### Scenario: 陌生会话不读他人日志

- **WHEN** 输入 session_id 为 X，但日志目录中只有会话 Y 的日志
- **THEN** 本轮不计量、不注入任何内容，更不读取 Y 的日志

### Requirement: 汇总视图标注会话来源

占用查询 SHALL 标注其数据来自最近活跃会话，避免多会话场景下被误读为当前会话的精确值。

#### Scenario: 查询标注来源

- **WHEN** 用户查询占用
- **THEN** 返回内容包含数据所属会话标识与更新时间
